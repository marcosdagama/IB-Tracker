# IB Tracker

Fortnightly tracker for the first term of the IB Diploma (DP1, 28 Sep – 18 Dec 2026).

- Six two-week sprints with can-do checklists for Physics HL and Maths AA SL (lead subjects), History, Business Management, English, Literature and the Core (TOK, CAS, EE).
- 1–4 self-check per lead subject and sprint, a confidence table, and a fortnight reflection box.
- Progress is stored in the browser (localStorage), so it stays on the device and browser where it was entered.

Open `index.html`, or publish with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
